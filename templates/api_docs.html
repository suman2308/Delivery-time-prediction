Authentication & headers

Send your key in the X-API-Key header — or as a Bearer token.

X-API-Key: scp_live_<your-key>
# or
Authorization: Bearer scp_live_<your-key>
Content-Type: application/json

Rate limits & errors

  • 1,000 requests / day per API key

Python

import requests

resp = requests.post(
    "https://courierai.example.com/api/predict",
    headers={"X-API-Key": "scp_live_YOUR_KEY"},
    json={
        "origin": "Mumbai",
        "destination": "Pune",
        "booking_weekday": "Wednesday",
        "mode": "Surface",
        "nature_of_consignment": "Dox",
        "total_pieces": 1,
        "actual_weight": 0.5,
        "volumetric_weight": 0.8,
        "chargeable_weight": 0.5,
    },
)
print(resp.json()["predicted_time_days"])  # 2.84
